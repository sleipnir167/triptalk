# ✈️ TripTalk — 旅の英会話トレーナー

iPad の Safari で快適に動き、ホーム画面に追加してアプリとして使える **旅行英語の総合学習 PWA** です。
ビルド不要の静的サイト（HTML / CSS / ES Modules）なので、どこにでも置くだけで動きます（英検3級パスポートと同じ構成）。

**公開URL：https://sleipnir167.github.io/triptalk/**（GitHub Pages）

## 使い方（iPad）

1. 上の URL を Safari で開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、全画面・オフラインで使えます。AI（内蔵AI）も設定なしで使えます

## クレジットを使わないための設計

0. **アプリ内蔵AI（Modellix の無料モデル）** が最初から使えます。利用者の設定・APIキー・料金は不要（下記）。
1. **採点はすべて端末内**（発音・クイズ・ディクテーション）。英作文・会話にも**無料チェック**（よくある文法ミス・和製英語・失礼に聞こえる言い方）が端末内で即時に出ます。AIは「解説・添削・会話」で押したときだけ。
2. **AI結果はすべて端末に保存**。同じ単語の解説・同じ文の添削は二度と課金されません。
3. **プロバイダの優先順位＋自動フォールバック**。無料（内蔵AI・自前Gemma・`:free`モデル）を上に置き、失敗時だけ有料へ。
4. **用途別の振り分け**：遅い自前サーバーは「解説・添削」専用、会話は速いモデルに。
5. **一括事前生成**：自前サーバーで苦手・未学習の解説を先に作っておけば、学習中は待ち時間ゼロ・無料。
6. **AI会話は1ターン1回の呼び出し**で返答・和訳・添削・ヒントをまとめて取得。最初のセリフは固定文で呼び出し不要。
7. **1日の呼び出し上限**（既定60回）と、OpenRouter の実費（usage.cost）を集計表示。

## 開発

```bash
npm start
```

`http://localhost:8765` で確認できます（Service Worker は localhost か HTTPS でのみ動きます）。

```bash
npm run check
```

コンテンツを検証します（ID の重複・必須項目・台本やシナリオの形式・採点の動作）。

### 公開・更新のしかた

GitHub Pages（`main` ブランチのルート）で公開しています。ファイルを変更したら、

```bash
npm run build-sw   # Service Worker のキャッシュ一覧とバージョンを更新
npm run check
git add -A && git commit -m "…" && git push
```

push すると数十秒〜数分でサイトに反映され、アプリ内に「新しいバージョンがあります」と表示されます。

## ほかの公開先（HTTPS が必須）

マイクと Service Worker は **HTTPS** でしか動きません。GitHub Pages 以外に置く場合：

- **Cloudflare Pages / Netlify**：このフォルダをそのままアップロード（ビルド設定なし）。内蔵AIを使うには、そのURLを中継サーバーの許可サイトに追加してください（[proxy/README.md](proxy/README.md)）。
- **すぐ試すだけなら**：`cloudflared tunnel --url http://localhost:8080` で発行される https URL を iPad で開く。
- **Oracle Cloud のサーバーで配信**（自前 Gemma と同居させるのがおすすめ。下記）。

公開後、Safari で開き **共有 → ホーム画面に追加**。全画面アプリとして起動し、オフラインでも学習できます（ホーム画面に追加すると学習データが消えにくくなります）。

### マイクについて
- iPad：設定 > 一般 > キーボード > **音声入力** をオン。Safari のサイト設定でマイクを許可。
- ブラウザ音声認識が使えない環境（PWA単体起動で不安定な場合など）は、**設定 > 音声 > 音声認識エンジン** を「入力」にすると、キーボードの🎤（iPadの音声入力）で答えられます。「AI」にすると Whisper 等で文字起こしします。
- Pixel / Chrome では Google の音声認識が無料で使えます（「オンデバイス認識を優先」も選択可）。
- 音声認識は息つぎで途切れないよう、話し終わって約2秒だまると自動で止まります（英検アプリで iPad Safari 検証済みの方式）。

## AI の設定（設定 > AI）

### アプリ内蔵AI（設定不要・無料）

**Modellix の無料 LLM（`modellix-ai/free-llm`）** があらかじめ組み込まれていて、何も設定せずに AI解説・AI先生に質問・AI添削・AI会話・AI通訳・フレーズ生成が使えます（英検3級パスポートと同じしくみ）。

```
TripTalk → AI 中継（Cloudflare Worker：英検アプリと共用）→ Modellix LLM
```

- Modellix の API はブラウザから直接呼べない（CORS 非対応）ので、Cloudflare Worker が中継します。**API キーは Cloudflare の Secret にだけ保存**され、アプリには入っていません
- 接続先は `js/config.js` の `BUILTIN_AI`。いまは英検アプリの中継サーバー（`eiken3-ai`）を共用しています
- 中継サーバーは**許可したサイトからだけ**受け付けます。公開URL（`https://sleipnir167.github.io/triptalk/`）は英検アプリと同じオリジンなので、そのまま動きます。別のURL（Cloudflare Pages や `http://localhost:8765`）で使うときは、英検アプリの `proxy/wrangler.toml` の `ALLOWED_ORIGINS` にそのURLを足して deploy してください。TripTalk 専用の中継にする手順は [proxy/README.md](proxy/README.md)
- 無料モデルは中で考える工程があり、返答まで数秒〜数十秒かかることがあります（画面に目安を表示）。形式が崩れた・空の返答のときは自動でやり直します
- 中継サーバーの回数制限は IP ごとに1分12回。「AI解説の一括事前生成」は自動で間隔をあけて呼びます
- 音声つきの呼び出し（AI発音診断・AI文字起こし）は中継しません。使うときは OpenRouter を追加してください

### 自分の AI を追加する（任意）

内蔵AIの下に追加すると、上から順に試し、失敗したら次へ進みます。内蔵AIを「会話に使う」からだけ外す、などの使い分けもできます。

| プリセット | ベースURL | モデル例 | メモ |
|---|---|---|---|
| OpenRouter | `https://openrouter.ai/api/v1` | `google/gemini-2.5-flash-lite`（安い）/ 末尾 `:free`（無料） | 「一覧」ボタンで価格・無料・音声対応で絞り込み可。音声モデルに `google/gemini-2.5-flash-lite`、文字起こしに `openai/whisper-1` |
| 自前サーバー (Gemma) | `https://あなたのドメイン/ollama/v1` | `gemma3:12b` など | 遅い場合は「解説・添削に使う」だけオン。system ロール非対応なら「system を使わない」をオン |
| Chrome内蔵AI | — | Gemini Nano | 対応Chromeのみ（iPad Safari不可）。無料・オフライン |
| カスタム | OpenAI互換のURL | — | ブラウザから呼べる（CORS対応の）API |

「接続テスト」で疎通確認できます。APIキーは端末内（IndexedDB）にだけ保存され、指定URL以外には送信しません。

### Oracle Cloud で アプリ＋Gemma(Ollama) を同じドメインで配信（Caddy）

同一オリジンにすると **CORS 設定不要・HTTPS 自動・混在コンテンツ問題なし** になります。

```caddyfile
triptalk.example.com {
	root * /srv/triptalk
	file_server

	handle_path /ollama/* {
		# 第三者に使われないよう合言葉を必須に（アプリのAPIキー欄に同じ値を入れる）
		@noauth not header Authorization "Bearer CHANGE_ME_SECRET"
		respond @noauth 401
		reverse_proxy 127.0.0.1:11434
	}
}
```

アプリ側の設定：ベースURL `https://triptalk.example.com/ollama/v1`、APIキー `CHANGE_ME_SECRET`、モデル `gemma3:12b`。
別ドメインで Ollama を公開する場合は `OLLAMA_ORIGINS=*` を設定し、必ず HTTPS 化してください。

## プロジェクト構成

```
index.html              エントリ（PWAメタ・スプラッシュ）
manifest.webmanifest    PWAマニフェスト（ショートカット: 復習/スピード周回/旅行モード）
sw.js                   Service Worker（scripts/build-sw.mjs で生成）
css/app.css             デザイン（ダーク/ライト・iPad/スマホ対応）
icons/                  アプリアイコン（SVG/PNG/maskable/apple-touch）
js/
  main.js router.js nav.js     起動・画面遷移・ナビ
  store.js                     IndexedDB 永続化・設定・AIキャッシュ・バックアップ
  srs.js                       FSRS-4.5 間隔反復・重み付き出題・予定
  scoring.js                   発話/入力の正規化・単語アラインメント・差分表示
  speech.js recorder.js        読み上げ・音声認識（ブラウザ/AI/キーボード）・録音→WAV
  ai.js                        内蔵AI・プロバイダ・フォールバック・キャッシュ・使用量・各種プロンプト
  config.js                    アプリ内蔵AIの接続先（中継サーバーのURL・モデル）
  wcheck.js                    英文の無料チェック（よくあるミス・和製英語・丁寧さ）
  gamify.js fx.js sfx.js       XP/レベル/スタンプ・紙吹雪・効果音
  components.js ui.js icons.js 共通UI
  data/scenes.js               単語・フレーズ（12シーン）
  data/dialogues.js            台本ロールプレイ・AI会話シナリオ・添削お題
  screens/*.js                 各画面
scripts/build-sw.mjs           プリキャッシュ一覧とバージョンの自動生成（npm run build-sw）
scripts/check-data.mjs         コンテンツの検証（npm run check）
proxy/                         AI 中継サーバー（Cloudflare Worker・TripTalk 専用にしたいとき用）
```

### コンテンツの追加
`js/data/scenes.js` に `[英語, 日本語, 例文, 例文訳, メモ]`（単語）または `['英語|別解|別解', 日本語, メモ]`（フレーズ）を追記するだけです。英語の先頭表現が学習履歴のIDになるため、既存項目の英語を変えると履歴はリセットされます。
